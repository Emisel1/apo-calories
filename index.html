Comment ça marche :
1. La clé est stockée uniquement sur cet appareil
2. Chaque entrée met à jour directement Google Sheets sur Drive
3. Les graphiques se recalculent automatiquement
4. Fonctionne à vie — pas de coût mensuel
Configuration (une seule fois) :
1. Ouvre Suivi_Apolline_V3 sur Google Sheets
2. Clique Extensions → Apps Script
3. Colle le script fourni (fichier apps-script.js dans le repo)
4. Déployer → Nouveau déploiement
   Type : Application Web · Accès : Tout le monde
5. Copie l'URL et colle-la dans le champ ci-dessus
Pourquoi Apps Script ? Script dans Google Sheets — gratuit, permanent, aucune clé API. Le site envoie les données, il les écrit dans l'onglet correspondant automatiquement.
